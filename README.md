# lucky

**決めるのはあなた。きっかけは偶然。**

小さな迷いを、あそびに。コイン・じゃんけん・カード・サイコロで「やる／やらない」を選び、メモと気持ちをカレンダーに残せるWebアプリです。結果に従う必要はありません。

## 2.0で追加
- スマホは下部、PCは左の3画面ナビ。「あそぶ / カレンダー / ことば」。ライト・ダーク対応。
- 4種類の抽選。各50％。じゃんけんのあいこは再挑戦。
- 抽選前の行動メモ、5種類の気持ち、自由記述。入力なしでも利用可能。
- 抽選結果と本人の選択を分けて保存。結果を見た気持ちも記録。
- 月カレンダー、日付ごとの記録、後日の追記、個別削除。
- 前向きな言葉・休んでもよい言葉・ことわざ19件。お気に入りと意味確認先。
- 旧記録の読み替え、1,000件までの保存、JSONバックアップ・復元。

仕様・注意点は [docs/V2.md](docs/V2.md) を参照してください。

## 開発
Node.js 22以降。アプリ本体は外部依存なし。

```sh
npm run dev
npm run check
npm run build
```

`http://127.0.0.1:4173` で起動。`public/`が実際の配信対象。ファイルの直接ダブルクリックではなくHTTP経由で開きます。

## 公開
GitHub： https://github.com/yutateru6-collab/lucky1

Cloudflare Worker名は `lucky1`。既存のCloudflare側Git連携（Workers Builds）で `main` の更新を公開する構成です。デプロイコマンドは `npx wrangler deploy`、ルートは `/`、配信元は `./public`。新たなGitHub Secretsの登録は不要です。一時Workerの新規作成や引き取りを通常の更新手順にしないでください。

GitHub保存と本番公開の成功は別です。実際に公開された内容を確認してからURLを案内してください。

## データと安全
記録は保存ボタンを押したときだけ、このブラウザのlocalStorageに保存します。アプリから個人メモを外部へ送信するコードはありません。ホスティング側ではページ配信のアクセス情報が扱われる場合があります。

自動同期はありません。ブラウザデータの削除、端末変更、URL変更で記録が見えなくなる場合があります。大切な記録は設定からバックアップしてください。バックアップは暗号化されていないJSONです。旧記録の移行は同じURLのブラウザ内に限られます。複数タブで同時に保存する場合の厳密なトランザクション保証はありません。

命・医療・危険・犯罪・大きなお金・緊急時の判断には使わないでください。キーワード検出は限定的な補助で、安全を保証しません。ストリーク、ペナルティ、行動の強制、達成済みという推測は加えません。
