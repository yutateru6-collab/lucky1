# lucky

**決めるのはあなた。きっかけは偶然。**

日常の小さな迷いに「やる / やらない」を50％ずつで提示するWebアプリです。出た結果には従わなくても構いません。

## 入っているもの

- 入力なしで使える50/50のコイントス。メモ入力は任意。
- コインのアニメーションと、動きを減らすOS設定への対応。
- 「コインの結果」と「自分で選んだこと」を分けた結果画面。
- 「やってみる」「今回はやめておく」「まだ決めない」の選択。
- 任意の気持ちの記録と、端末内だけに保存する「あしあと」。最大100件。保存上限時に既存記録を自動削除しません。
- ライト / ダーク表示、スマートフォン / PCのレスポンシブレイアウト。
- PWA用アイコン・manifest・Service Worker。
- Cloudflare Workers Static Assets用設定と、Cloudflare Pagesでもそのまま配信できる静的ファイル。
- コンセプト・運用上の注意・検証範囲の文書。

ログイン、AI、広告、分析タグ、位置情報取得、写真アップロード、サーバー側の個人データ保存は実装していません。行動を強制するポイント、ストリーク、未達ペナルティもありません。

## ローカルで起動

Node.js 22以降を用意します。通常の起動・ビルド・単体テストには外部パッケージのインストールは不要です。

```sh
npm run dev
# http://127.0.0.1:4173
```

```sh
npm run check   # 構文チェックと単体テスト
npm run build   # public/ を dist/ にコピー
```

開発サーバーはデフォルトで127.0.0.1だけにバインドします。共有を意図する場合に限り `HOST=0.0.0.0 npm run dev` とします。公開運用に開発サーバーは使用しません。

`index.html` の直接ダブルクリックではなく、HTTPサーバー経由で開いてください。JavaScript Modulesを使用しています。

## Cloudflareへ公開

詳しい手順は [docs/DEPLOY.md](docs/DEPLOY.md) を参照してください。

### Workers Static Assets

`wrangler.jsonc` に公開ディレクトリ `./public` を設定済みです。

```sh
npx wrangler@4 login
npm run deploy
```

`npm run deploy` はWranglerを取得するためネットワーク接続とCloudflare認証が必要です。CLIに表示された実際の公開URLを使ってください。

### Pages

Git連携で静的サイトとして公開する場合の設定：

| 項目 | 値 |
| --- | --- |
| Framework preset | None |
| Production branch | 実際にコードを入れたブランチ（新規構成では main） |
| Build command | `exit 0` |
| Build output directory | `public` |

プロジェクト全体ではなく、`public/` の内容だけが配信対象です。

## 確率

`crypto.getRandomValues` が返す32ビット整数を、`2^31` 未満か以上かで分けます。それぞれにちょうど `2^31` 個の値が対応します。履歴・選択・演出の都合で結果を引き直したり、確率を変えたりしません。同じ結果が続く場合があります。有限回の試行結果が必ず半々になるという意味ではありません。

## 保存とプライバシー

「あしあとに残す」を押した記録だけを `localStorage` に保存します。入力内容・抽選結果・記録をアプリから外部サーバーへ送信するコードはありません。テーマ設定も端末に保存されます。ページ配信に伴うアクセス情報はホスティングサービス側で扱われる場合があります。

ブラウザのデータ削除、端末の変更などで記録が失われる場合があります。同期・バックアップ・暗号化保管はありません。個人情報や秘密は書かないことを勧めます。複数タブから同時に保存する場合、厳密なトランザクション保証はありません。

## 安全上の範囲

日常の小さな、安全な判断だけに使います。命・医療・緊急時の救助・危険・犯罪・大きなお金などの判断に使わないでください。

自由入力には一部の言葉を検出して抽選を止める補助があります。ただし安全を保証するものではなく、書かれていない状況や文脈を理解できません。注意書きを消したり、「危険な内容は必ず防げる」と表現したりしないでください。
