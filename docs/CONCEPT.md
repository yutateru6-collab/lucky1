# lucky — プロダクトの核

## 定義

迷ったとき、50％の偶然を借りて、いつもの自分とは少し違う選択をしてみるアプリ。

出た結果に従ってもいい。従わなくてもいい。自分一人なら選ばなかった可能性を、いったん目の前に出す。

- メインコピー：**決めるのはあなた。きっかけは偶然。**
- 世界観のコピー：**いつもの自分に、ちいさな偶然を。**
- ブランドの方向：**いつもの自分なら、選ばないほうへ。**

## 何のために使うか

気になっているお店に入るか。友達に連絡するか。普段は選ばない本を開くか。

「少しやってみたい。でも、いつもの自分なら見送るかもしれない」と迷ったときに使う。「コインがそう出たから、ちょっとやってみよう」という気軽なきっかけをつくる。

誰かに声をかける例も、相手の意思と安全を尊重できる日常的な場面に限る。救命や緊急対応を抽選で先延ばしする用途にはしない。

## 最初の操作は、とても短く

1. アプリを開く。迷っている内容は入力しなくてもよい。
2. コインを投げる。
3. 「やる / やらない」が各50％で出る。
4. 出た結果を見る。行動を変えなくてもよい。

ここまでで利用は完結する。記録・振り返りは任意。

## 追加で残せること

- 迷っていたことの短いメモ。
- コインの結果。
- その結果を見た後、自分がどちらを選んだか。「まだ決めない」も可。
- 結果を見たときの気持ち。

「やってみる」を押したことと、現実に行動を終えたことは区別する。初版は行動の完了を検証しないので、「何回行動した」「何人を助けた」とは表示しない。

## 世界観

小さな分岐に、コインをひとつ。温かい紙のような背景、深い緑、柔らかな金色。派手なカジノ、勝ち負け、占いによる断定、命令するキャラクターには寄せない。

コインの表裏は優劣ではない。「やらない」が出ても残念演出や失敗音を出さない。結果画面では、本人の選択を同じ扱いで並べる。

## 初版に入れないもの

デイリーミッション、連続ログイン記録、ランキング、SNS公開、友達への強制参加、位置情報、AI推薦、確率調整、課金による引き直し。

まずは「必要な瞬間にすぐ開ける」「出た結果が気持ちを動かす」「自分で選べる」が成立するかを確かめる。

## 成功をどう捉えるか

利用時間の長さではなく、「このアプリがなかったら、これをやっていなかったかもしれない」と本人が感じる場面を目指す。反対の選択をしたことや、使わない日があることは失敗ではない。

これらの価値が実際に得られるかは未検証。初版を使ってもらい、率直な感想を聞いて改善する。
