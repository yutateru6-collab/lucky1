# 背中を押す版 /gentle/ — lucky 4.0.0

公開先（反映はActionsの実測で確認）：https://lucky1.itisnowornever271.workers.dev/gentle/

## 既存デザインを上書きしない

作業中、mainに承認済みパステルデザインの更新 a125df2 が入ったため、その更新を全面維持。ルートのHTML/CSS/JS・画像・既存テスト・Cloudflare設定を変更せず、今回の体験を /gentle/ 以下へ分離して比較可能にした。別のデザインを主画面に強制採用しない。

## 体験

迷い → 公平な偶然 → 結果を見た本音 → 本人の選択 → 任意の最初の一歩 → 自分だけの記録。

ホームから入力なしで1タップ抽選。5つの道具は切替に集約。紙色と深緑、モバイル下部ナビ・デスクトップ上部ナビ、夜色と動きを減らす設定。具体的な日常の例からメモを始められる。

結果に従う義務はない。反対・見送り・保留・記録せず終了を同等に尊重。本人の選択は見た目で初期選択しない。選択して初めて任意の一歩欄が開く。記録は実行済みの証拠として扱わない。

既存v1/v2記録・下書き・ことばを保持。カレンダーの空の日を正しく表示し、メモと振り返りを検索・編集。保存失敗時に成功を表示しない。破損データは上書きせず救出可能。メモを外部送信せず、HTMLとして挿入しない。

## 互換性

同一ブラウザでは既存のlucky.records.v1/v2などを共用し、相互に記録を見られる。Service Workerは /gentle/ スコープ、キャッシュは lucky-gentle-shell- 名前空間に分離し、既存版のキャッシュを削除しない。アプリ紹介は従来のluckyトップURLを共有し、個人のメモは共有しない。

PNGアイコンは scripts/generate-gentle-icons.mjs が /gentle/icons/ だけに生成。npm test/build前に自動実行され、既存アプリのアイコンを変更しない。元のベクトル形状から追加依存なしで再現可能。

## 検証

専用Actionsで単体テスト、厳格なCSP下のブラウザ操作・全5抽選・保存と破損保護・旧記録・幅320〜1440・本物のService Workerによるオフライン再読込を確認する。

main反映後、公開 /gentle/ のファイルSHA256をソースと照合し、公開画面の操作・モバイル/PCスクリーンショット・オフライン動作も実測する。GitHubへの保存だけで公開済みと判定しない。
