# Quick Mode 4.1 — 小さなマンネリを、1°ずらす

## コンセプト

luckyは「大きな人生の決断を代わりにする」ものではない。対象は、日常でいつもなら流してしまう小さな選択。

- 気になった店に入るか。
- いつもと違う道を歩くか。
- ひとこと声をかけるか。
- 5分だけ新しいことを試すか。

こうした小さな「やる？やらない？」を、その場で止まらず決める。いつもと少し違う選択が、今日の流れや出会いを少し変えるかもしれない。その積み重ねでマンネリをゆるく崩す。

## 即決モード

入力はゼロ。ホームの「今すぐ決める」から、50/50で「やってみる / 今回はやめる」を出す。

結果は命令ではない。見た瞬間に「逆がいい」と思ったら、それも本人の答えとして扱う。

メモは決める前ではなく**決めた後**。必要な人だけ「何を決めた？」「ひとこと」を残す。メモなしで閉じた場合は記録しない。

## 既存モードとの役割分担

- 即決モード: その場の小さな迷いを10秒で終わらせる。
- メモして決める: 気持ちや背景も整理したいとき。

重大な健康・安全・法律・大きなお金の判断には使わない。即決モードは入力がないため自動判定はできず、画面上で用途を明示する。
