# 初版の確認範囲

## 実施済み

- Node.jsによるJavaScript構文チェック。
- 14件の単体・静的アセットテスト。
- 32ビット乱数の境界値検査。各結果に2^31個ずつの値が対応すること。
- 22項目のChromiumによるオフラインDOMテスト。
- 320×568、390×844、768×1024、1440×1000の横方向はみ出し確認。
- 結果に反対する選択、未決定、任意保存、削除確認、入力文字の無害な表示。
- 連打時の単一抽選と、アニメーション中の画面移動によるキャンセル。
- ストレージ保存エラー時に「保存済み」と偽って表示しないこと。
- ライト・ダークの画面画像確認と、主要な文字色のコントラスト計算。
- `npm run build` の実行。

## 制約と未確認

今回のブラウザ環境ではローカルHTTPサーバーへの移動が `ERR_BLOCKED_BY_ADMINISTRATOR` になりました。そのためアクセス制限の変更はせず、作成したHTML/CSS/JavaScriptをネットワークなしでブラウザ内に読み込んで操作しました。

DOMテストの保存領域はメモリ型のテスト用アダプターです。結果表示を安定して検査するため、DOMテストでは乱数にもテスト用の値を使います。製品コードにこれらの差し替えは入れていません。本体の乱数処理は、単体テストで実際のWeb Cryptoを含めて別途検査しました。

以下は未確認です：実際のCloudflareへのデプロイ、公開URLでのレスポンスヘッダー・モジュール配信、ブラウザ本来の永続ストレージを用いた再読み込み、Service Workerによる実オフライン動作、PWA追加、iPhone/Android実機。

入力のキーワード検出は部分的な補助であり、危険な判断を完全に検出できるものではありません。利用者への有効性、利用継続率、実際の行動変化も未検証です。

## 再実行

```sh
npm run check
npm run build
```

オフラインDOMテストは別途Python版PlaywrightとChromiumが必要です。

```sh
python tests/ui_offline_test.py
# 必要なら CHROMIUM_PATH で実行ファイルを指定
```

テスト用の出力は `test-results/` に作成されます。本番には公開しません。
